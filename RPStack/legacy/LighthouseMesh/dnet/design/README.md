# DistNet Design

This directory holds design-facing documentation for the `dnet` project.

## Layout

- `adr/`
  - Architecture decision records for durable protocol and system choices.
- `execution/`
  - Execution subsystem design notes.
- `messaging/`
  - Messaging and composition protocol design notes.

## Current State

The implementation under `src/messaging` still reflects the earlier service-discovery protocol.
The documents in `design/messaging` describe the replacement composition protocol discussed for future implementation.
